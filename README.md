# 🛡️ ScamShield AI — AI-Powered Online Scam Detection

**ScamShield AI** is an intelligent cybersecurity project designed to identify potential online scams by analyzing suspicious messages and URLs using machine learning, explainable risk assessment, and an experimental quantum-classical computing approach.

## 🚀 Project Overview

Online scams, phishing messages, and fraudulent links are growing digital security concerns. ScamShield AI aims to help users recognize suspicious communications by highlighting warning signs and providing practical safety recommendations.

## ✨ Key Features

- **AI-Based Scam Detection:** Classifies messages as potentially suspicious or less suspicious using machine learning.
- **Phishing URL Analysis:** Examines URLs for common warning signs.
- **Risk Assessment:** Provides a prototype risk score and risk category.
- **Explainable Results:** Displays warning signs that contribute to the assessment.
- **Quantum Computing Experiment:** Uses Qiskit to explore quantum-circuit simulation alongside classical machine learning.
- **Interactive Web Interface:** Provides a simple web application built with Flask.
- **Safety Recommendations:** Offers guidance for safer online communication.

## 🛠️ Technology Stack

- Python
- Flask
- Scikit-learn
- NumPy
- Qiskit
- Qiskit Aer
- HTML5 and CSS3

## 🏗️ System Architecture

User Input → Flask Web Interface → Scam Detection Engine → Machine Learning and URL Analysis → Risk Assessment → Safety Recommendations

An experimental quantum-circuit module is included to explore quantum computing concepts. It is not assumed to outperform classical machine learning.

## ⚙️ Installation and Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/ScamShield-AI.git
   ```

2. Navigate to the project directory:

   ```bash
   cd ScamShield-AI
   ```

3. Create a virtual environment:

   ```bash
   python -m venv venv
   ```

4. Activate it on Windows PowerShell:

   ```powershell
   .\venv\Scripts\Activate.ps1
   ```

5. Install dependencies:

   ```bash
   python -m pip install -r requirements.txt
   ```

6. Start the application:

   ```bash
   python app.py
   ```

7. Open the following address in your browser:

   `http://127.0.0.1:5000`

## ⚠️ Limitations

This is an educational prototype, not a guaranteed scam detector. Results depend on the training data and detection rules. A low risk score does not prove that a message is safe. The experimental quantum module does not establish quantum advantage.
